T4 - FIX CODE
Status: PASS
Buggy code tested:
def calculate_average(numbers):
    total = 0
    for num in numbers:
        total = num
    return total / len(numbers)

marks = [80, 90, 100]
print(calculate_average(marks))

Observed:
- AI identified the accumulator bug (total = num).
- Suggested using total += num.
- Also suggested handling an empty list.
- Correct average for the test data: 90.0.
