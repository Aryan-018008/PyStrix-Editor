01 / OVERVIEW

What is Python?

Python is a high-level, general-purpose programming language known for its readable syntax and versatility. It is used in web development, automation, data analysis, artificial intelligence, scripting and many other fields.

Why Learn Python?

  • Easy-to-read and beginner-friendly syntax.
  • Supports procedural, object-oriented and functional programming styles.
  • Has a large standard library.
  • Useful for automation, web development, data science and more.
  • Has a large developer community.

Important Characteristics

Readable

Simple syntax makes programs easier to understand.

Versatile

Supports multiple programming paradigms.

Extensible

Can use modules and third-party packages.

Cross-platform

Available on major operating systems.

03 / FUNDAMENTALS

Python Syntax & Comments

Syntax refers to the rules used to write valid Python programs. Python uses indentation to define blocks of code.

Indentation

PYTHON
if 10 > 5:
    print("Ten is greater than five")
    print("This is inside the if block")

print("This is outside the block")

Python commonly uses four spaces for each indentation level.

Single-line Comments

PYTHON
# This is a comment
print("Hello Python")

Multi-line Documentation Strings

PYTHON
"""
This is a documentation string.
It can describe a module or function.
"""

def greet():
    """Display a greeting."""
    print("Hello!")
04 / FUNDAMENTALS

Variables

A variable is a name that refers to an object or value in memory. You do not need to declare a variable's type explicitly in Python.

Creating Variables

PYTHON
name = "Aryan"
age = 21
height = 5.8

print(name)
print(age)
print(height)

Variable Naming Rules

  • A variable name can contain letters, numbers and underscores.
  • It cannot start with a number.
  • Variable names are case-sensitive.
  • Python keywords cannot be used as variable names.
  • Use descriptive names for better readability.

Multiple Assignment

PYTHON
a, b, c = 10, 20, 30

print(a, b, c)

x = y = z = 100

print(x, y, z)

09 / CONTROL FLOW

Conditional Statements

Conditional statements allow a program to make decisions based on whether a condition is true or false.

if Statement

PYTHON
age = 20

if age >= 18:
    print("You are an adult")

if-else Statement

PYTHON
number = 7

if number % 2 == 0:
    print("Even number")
else:
    print("Odd number")

if-elif-else Statement

PYTHON
marks = 85

if marks >= 90:
    print("Grade A+")
elif marks >= 75:
    print("Grade A")
elif marks >= 60:
    print("Grade B")
else:
    print("Grade C")

Nested Conditions

PYTHON
age = 21
has_id = True

if age >= 18:
    if has_id:
        print("Entry allowed")
    else:
        print("ID required")
else:
    print("Entry denied")
10 / CONTROL FLOW

Loops

Loops repeat a block of code. Python provides for and while loops.

for Loop

PYTHON
for i in range(1, 6):
    print(i)

Understanding range()

PYTHON
print(list(range(5)))
print(list(range(1, 6)))
print(list(range(2, 11, 2)))

while Loop

PYTHON
count = 1

while count <= 5:
    print(count)
    count += 1

Always ensure that a while loop has a suitable stopping condition. Otherwise, it may run indefinitely.

11 / CONTROL FLOW

Loop Control Statements

break

Terminates the nearest enclosing loop.

PYTHON
for i in range(1, 10):
    if i == 5:
        break
    print(i)

continue

Skips the remaining statements in the current loop iteration.

PYTHON
for i in range(1, 6):
    if i == 3:
        continue
    print(i)

pass

Acts as a placeholder statement that performs no operation.

PYTHON
for i in range(3):
    pass

print("Program continues")

18 / FUNCTIONS

Lambda Functions

A lambda function is a small anonymous function written using the lambda keyword. It contains a single expression.

PYTHON
square = lambda x: x * x

print(square(5))

add = lambda a, b: a + b

print(add(10, 20))

Lambda functions are often used for short operations, including as arguments to functions such as sorted().

19 / FUNCTIONS

Recursion

Recursion occurs when a function calls itself. A recursive function needs a base case to stop further calls.

PYTHON
def factorial(n):

    if n == 0:
        return 1

    return n * factorial(n - 1)

print(factorial(5))
OUTPUT
120

21 / ERROR HANDLING

Exception Handling

Exceptions are errors detected during program execution. Python provides try and except to handle them.

try-except

PYTHON
try:
    number = int(input("Enter a number: "))
    print(100 / number)

except ValueError:
    print("Please enter a valid integer.")

except ZeroDivisionError:
    print("Cannot divide by zero.")

else and finally

PYTHON
try:
    number = int("100")

except ValueError:
    print("Invalid value")

else:
    print("Conversion successful")

finally:
    print("Execution completed")

Raising an Exception

PYTHON
age = 15

if age < 18:
    raise ValueError("Age must be 18 or above")

File Handling

Python provides built-in functions to read from and write to files. The open() function opens a file.

File Modes

ModePurpose

23 / OBJECT-ORIENTED PROGRAMMING

Object-Oriented Programming (OOP)

OOP organizes programs using classes and objects. It helps structure data and behaviour together.

Class and Object

PYTHON
class Student:

    def greet(self):
        print("Hello, student!")

student1 = Student()
student1.greet()

Constructor: __init__()

PYTHON
class Student:

    def __init__(self, name, age):
        self.name = name
        self.age = age

    def display(self):
        print(self.name, self.age)

student = Student("Aryan", 21)
student.display()

Inheritance

PYTHON
class Animal:

    def sound(self):
        print("Animal makes a sound")


class Dog(Animal):

    def bark(self):
        print("Dog barks")


dog = Dog()
dog.sound()
dog.bark()

Polymorphism

PYTHON
class Dog:
    def sound(self):
        print("Bark")


class Cat:
    def sound(self):
        print("Meow")


for animal in [Dog(), Cat()]:
    animal.sound()

Encapsulation

PYTHON
class BankAccount:

    def __init__(self, balance):
        self.__balance = balance

    def get_balance(self):
        return self.__balance


account = BankAccount(5000)

print(account.get_balance())

Python uses naming conventions and name mangling for attributes such as __balance. This is not strict access control.

24 / ADVANCED PYTHON

Comprehensions

Comprehensions provide a concise way to create collections from existing iterables.

List Comprehension

PYTHON

print(squares)

List Comprehension with Condition

PYTHON
even_numbers = [
    x for x in range(1, 11)
    if x % 2 == 0
]

print(even_numbers)

Dictionary Comprehension

PYTHON

    x: x * x for x in range(1, 6)
}

print(squares)
25 / ADVANCED PYTHON

Iterators & Generators

Iterators

An iterator is an object that implements the iterator protocol using __iter__() and __next__().

PYTHON
numbers = [10, 20, 30]

iterator = iter(numbers)

print(next(iterator))
print(next(iterator))
print(next(iterator))

Generators

Generators produce values lazily, usually using the yield keyword.

PYTHON
def count_up_to(n):

    for i in range(1, n + 1):
        yield i


for number in count_up_to(5):
    print(number)
